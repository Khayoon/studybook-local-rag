# Build a useful bilingual glossary notebook

This is an original demonstration document. Its example terms and translations are placeholders for a learner to complete, not authoritative terminology.

## One entry, several kinds of information

Record the source expression, a proposed equivalent, a short explanation, the source context, and a sentence you wrote yourself. Add a confidence label: "needs checking," "reviewed," or "comfortable in this context."

For a phrase with several meanings, create separate context notes. A word used in a classroom may need a different equivalent when it appears in a business conversation.

## Suggested fields

| Field | Example content |
| --- | --- |
| Source expression | appointment |
| Proposed equivalent | Add an equivalent in your target language |
| Context | Scheduling a meeting with a tutor |
| Example sentence | I would like to move our appointment to Friday. |
| Confidence | needs checking |
| Review action | Ask a study partner to compare two alternatives |

## Review with retrieval practice

Cover the proposed equivalent and try to recall it from the source expression and context. Then reverse the direction. If recall fails, use the phrase in a new sentence before trying again later.

Choose five entries for a practice session. The number five is a manageable sample for this demonstration, not a universal rule. Move entries back into review when their meaning or usage becomes uncertain.

## Avoid isolated word lists

A list can help collect terms, but context makes it easier to choose among alternatives. Keep the original source reference so you can return to the passage when a translation feels ambiguous.
